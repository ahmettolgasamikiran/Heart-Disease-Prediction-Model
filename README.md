# Heart-Disease-Prediction-Model
A machine learning model predicting heart disease risk using Python and Scikit-learn.

## About the Project
This project predicts the risk of heart disease using Machine Learning. It analyzes patient data (like age, blood pressure, and cholesterol) to see if there is a health risk.
My goal is to show how Python and Data Science can help in the medical field.

## 🔑 Key Features
* **Algorithm:** I used the Gradient Boosting Classifier (from Scikit-Learn).
* **Accuracy:** The model achieved **~87% accuracy** on the test set.
* **Data Analysis:** I created new features like "Cardio Load" to improve results.

## 📂 Dataset Info
The model uses clinical data with these inputs:
* Age & Sex
* Resting Blood Pressure
* Cholesterol Levels
* Max Heart Rate

## 🛠️ Technologies
* **Language:** Python
* **Libraries:** Pandas, Scikit-Learn, Joblib
* **File Type:** The trained model is saved as a `.pkl` file.

## 🚀 How to Run
1.  Download the files from this repository.
2.  Install the required libraries:
    ```bash
    pip install pandas scikit-learn joblib
    ```
3.  Run the python script:
    ```bash
    python model.py
    ```
